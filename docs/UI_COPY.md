# UI copy

Write agent messages as a friendly teammate speaking directly to the founder.
Keep them brief and natural, with a clear purpose.

Use `AgentTypingText` for agent speech bubble messages so they share the same
quick typing reveal. Respect reduced motion and reserve the message height.

Do not use hyphens, en dashes, or em dashes in authored UI copy or agent messages.
Use short sentences, commas, or rephrase instead. Preserve technical identifiers,
URLs, file paths, and verbatim user or source content.
